# Jerry's Singing Tuner

Play a note on the on-screen keyboard, sing it back, and watch the tuner needle.

Live site: https://jerrysu11.github.io/vocal/

## Use it on your phone

1. Open the link above in Safari (iPhone) or Chrome (Android).
2. Tap **Share → Add to Home Screen** (iPhone) or **⋮ → Add to Home screen** (Android).
3. Launch it from the home screen. Tap **Enable Mic** and allow microphone access.

Everything runs in the browser. No audio is uploaded anywhere.
